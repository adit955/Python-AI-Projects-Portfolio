\cf0 About the Project\
\pard\pardeftab720\sa240\partightenfactor0

\f1\b0 \cf0 Life Pattern Detective is a Python-based data analytics project that I developed to understand how daily habits can affect a person's routine and overall lifestyle.\
The idea behind this project is simple: we follow different habits every day, such as sleeping, studying, exercising, and spending time on our phones, but we may not always notice the patterns in them. This project helps organise those daily activities and turn the recorded information into useful insights.\
I built this project to practise Python programming and learn how data analytics can be used in everyday life. Instead of just storing information, the application analyses the records and presents the results through summaries and visual charts.\
\pard\pardeftab720\sa298\partightenfactor0

\f0\b \cf0 Problem Statement\
\pard\pardeftab720\sa240\partightenfactor0

\f1\b0 \cf0 People often record their daily activities without analysing how their habits change over time. Without reviewing this information, it can be difficult to understand how much time is spent studying, whether sleep routines are consistent, or how daily habits relate to mood.\
Life Pattern Detective addresses this problem by organising daily lifestyle records and providing a simple way to review them.\
\pard\pardeftab720\sa298\partightenfactor0
