# SafeRoute Companion

## About the Project

SafeRoute Companion is a Python project designed to help users record their journeys and keep track of their travel check-ins. It also includes emergency contact details to make important travel information easier to manage.

I developed this project to understand how Python, Flask, and SQLite can work together to create a simple travel-support application.

## Problem Statement

When travelling, it can be useful to keep journey details, check-in information, and emergency contact details in one place. Managing these details separately can be inconvenient.

SafeRoute Companion provides a simple way to record and view this information.

## Technologies Used

- **Python:** Used to write the main application logic.
- **Flask:** Used to create the web application.
- **SQLite:** Used to store journey and related information in a database.
- **Jupyter Notebook:** Used to develop and test the project.

## Main Features

- Add and manage journey details.
- Record starting points and destinations.
- Track journey status.
- Record travel check-ins.
- Store emergency contact information.
- View journey records.
- Export journey information to a CSV report.

## How the Project Works

1. The user enters journey details, such as the starting location and destination.
2. The application stores the journey information in the database.
3. The user can record check-ins and view journey status.
4. Emergency contact details can be maintained for reference.
5. Journey information can be exported as a CSV report.

## What I Learned

While developing this project, I learned how to use Python for application logic, Flask for building a web application, and SQLite for storing data. I also gained practical experience working with journey records, check-ins, and CSV reports.

## Future Improvements
